## 在 GitHub 发布

1. 登录 Prdgz 账号，访问 https://github.com/new ，新建名为 prdgz.github.io 的 Public（公开）仓库。
   如果该仓库已经存在，先检查现有内容，不要直接覆盖已有网站。
2. 解压本 ZIP，在仓库使用 Add file → Upload files，将解压出来的文件上传到仓库根目录并提交到 main。
   index.html 必须直接位于根目录，不要只上传 ZIP，也不要把文件放进一层外部文件夹。
3. 打开 Settings → Pages，在 Build and deployment 下选择 Deploy from a branch，选择 main 和 /(root)，点击 Save。
4. 等待 GitHub 部署完成，访问 Pages 设置中给出的实际网站地址。目标为 https://prdgz.github.io/ 。

无需安装依赖、运行构建、租用服务器或使用学校账号。
如果新建仓库的页面没有 Add file，可使用页面中的 uploading an existing file 链接上传。
